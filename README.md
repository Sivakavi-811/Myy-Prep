# Problem Solving Repository

A structured collection of solved problems across **Data Structures & Algorithms**, **LeetCode**, and **Quantitative Aptitude**, each committed individually.

## Structure

```
DSA/
  Arrays/  Strings/  LinkedList/  Trees_and_Graphs/  Dynamic_Programming/
LeetCode/
  Easy/  Medium/  Hard/
Aptitude/
  Quantitative/  Logical_Reasoning/
```

## Conventions

- **File naming:** `ProblemNumber_ProblemName.ext` (e.g. `0001_TwoSum.py`, `01_TimeAndWork.md`)
- **Code files:** Python, each with a header covering the problem, approach, and time/space complexity, plus runnable test cases under `if __name__ == "__main__":`.
- **Aptitude files:** Markdown with the question, shortcut/formula, step-by-step working, and the final answer.

## Running a solution

```bash
python LeetCode/Easy/0001_TwoSum.py
```
