# 06 — Ratio and Proportion

## Key Formulas & Shortcuts

| Concept | Formula |
|---|---|
| Dividing an amount S in the ratio a : b | Shares = **S × a/(a+b)** and **S × b/(a+b)** |
| Combining A : B and B : C | Make **B equal** in both ratios, then join them |
| Proportion a : b = c : d | **a × d = b × c** (product of extremes = product of means) |
| Mean proportional of a and c | **√(a × c)** |
| Fourth proportional to a, b, c | **d = b × c / a** |

> **Unit method:** Write a ratio a : b as **ak** and **bk**, solve for k, then multiply back. This works for almost every ratio problem.

## Question 1

Divide **₹1,200** between A and B in the ratio **3 : 5**.

### Solution

1. Total parts = 3 + 5 = **8**
2. A = 1200 × 3/8 = **₹450**
3. B = 1200 × 5/8 = **₹750**

### ✅ Answer: **A = ₹450, B = ₹750**

## Question 2

If **A : B = 2 : 3** and **B : C = 4 : 5**, find **A : B : C**.

### Solution

1. B is 3 in the first ratio and 4 in the second. Make both equal to LCM(3, 4) = 12.
2. A : B = 2 : 3 = **8 : 12** (multiply by 4)
3. B : C = 4 : 5 = **12 : 15** (multiply by 3)
4. So A : B : C = **8 : 12 : 15**

### ✅ Answer: **8 : 12 : 15**

## Question 3

Two numbers are in the ratio **5 : 7**. If **6** is added to each, the ratio becomes **3 : 4**. Find the numbers.

### Solution

1. Let the numbers be 5k and 7k
2. (5k + 6) / (7k + 6) = 3/4
3. Cross-multiply: 4(5k + 6) = 3(7k + 6), so 20k + 24 = 21k + 18
4. k = **6**, giving the numbers 30 and 42

**Check:** 36 : 48 = 3 : 4 ✔

### ✅ Answer: **30 and 42**

---

## Takeaways

- To join two ratios, make the shared term equal using the LCM.
- Write unknowns as **ak** and **bk** so you only have to solve for one variable.
- Check your answer by putting it back into the original ratio.
