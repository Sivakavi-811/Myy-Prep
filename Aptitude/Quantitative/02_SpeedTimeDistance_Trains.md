# 02 — Speed, Time & Distance (Problems on Trains)

## Key Formulas & Shortcuts

| Concept | Formula |
|---|---|
| Basic relation | **Distance = Speed × Time** |
| km/h → m/s | Multiply by **5/18** |
| m/s → km/h | Multiply by **18/5** |
| Train passes a pole / person (point object) | Distance = **length of train** |
| Train passes a platform / bridge | Distance = **train length + platform length** |
| Opposite directions | Relative speed = **S₁ + S₂** |
| Same direction | Relative speed = **S₁ − S₂** |
| Two trains crossing each other | Distance = **L₁ + L₂** |

> **Unit trap:** Lengths are usually in metres and speeds in km/h. Convert the speed to m/s **before** dividing.

---

## Question 1

A train **150 m** long is running at **54 km/h**. How long will it take to cross a platform **250 m** long?

### Solution

1. Speed = 54 × 5/18 = **15 m/s**
2. Distance = train + platform = 150 + 250 = **400 m**
3. Time = 400 ÷ 15 = **26.67 s** (26 2/3 s)

### ✅ Answer: **26 2/3 seconds ≈ 26.67 s**

---

## Question 2

Two trains of lengths **120 m** and **180 m** run on parallel tracks in **opposite directions** at **50 km/h** and **40 km/h**. How long will they take to cross each other completely?

### Solution

1. Relative speed (opposite directions) = 50 + 40 = **90 km/h**
2. Convert: 90 × 5/18 = **25 m/s**
3. Distance to cover = 120 + 180 = **300 m**
4. Time = 300 ÷ 25 = **12 s**

### ✅ Answer: **12 seconds**

**Follow-up:** If they ran in the **same direction**, relative speed = 50 − 40 = 10 km/h = 25/9 m/s, so time = 300 ÷ (25/9) = **108 s**.

---

## Takeaways

- Decide first **what distance is being covered**: the train's own length, train + platform, or both trains' lengths.
- Add speeds when the trains move toward each other; subtract them when they move the same way.
