# 07 — Analogies

## Approach & Shortcuts

An analogy question gives a pair **A : B** and asks for the pair **C : ?** that shares the **same relationship**. First name the relationship as a short sentence, then apply that sentence to C.

| Relationship type | Example |
|---|---|
| Worker : Tool | Carpenter : Saw |
| Product : Raw material | Paper : Pulp |
| Part : Whole | Petal : Flower |
| Animal : Young one | Dog : Puppy |
| Animal : Home | Bee : Hive |
| Unit : Quantity | Ampere : Current |
| Number relationship | 3 : 27 (n : n³) |
| Letter shift | AB : DE (each letter +3) |

> **Tip:** Make the relationship specific. "Related to" is too vague. Use something like "is the young one of".

---

## Question 1

**Doctor : Hospital :: Teacher : ?**

### Solution

1. Relationship: *a doctor works in a hospital*
2. A teacher works in a **school**

### ✅ Answer: **School**

---

## Question 2

**4 : 64 :: 6 : ?**

### Solution

1. 4³ = 64, so the relationship is *n : n³*
2. 6³ = **216**

### ✅ Answer: **216**

---

## Question 3

**ACE : BDF :: GIK : ?**

### Solution

1. A → B, C → D, E → F, so each letter moves **+1**
2. G → H, I → J, K → L

### ✅ Answer: **HJL**

---

## Question 4

**Cow : Calf :: Horse : ?**

### Solution

1. Relationship: *a calf is the young one of a cow*
2. The young one of a horse is a **foal**

### ✅ Answer: **Foal**

---

## Takeaways

- Write the relationship as a sentence, then check the answer options against it.
- For numbers, try squares, cubes, n² ± 1, and multiples.
- For letters, write down the position numbers and look for a fixed shift.
